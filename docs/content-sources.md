# 원문 기반 학습 자료 출처 기록

외부 원문을 직접 확인해 만든 자료의 출처와 확인 내용을 남긴다. 알 수 없는 정보는 추정하지 않고 "알 수 없음"으로 적는다. 가상 예시 자료 11개는 원문이 없으며 이 문서의 대상이 아니다.

## 만드는 기준

- 공개적으로 접근 가능한 공식 문서나 신뢰할 수 있는 원저자의 글을 **직접 열어 확인한 것만** 쓴다. 확인할 수 없으면 출처나 내용을 만들지 않는다.
- 원문 전체를 복제하거나 긴 번역문을 싣지 않는다. 핵심 주장, 근거, 예시는 Stack이 직접 쓴 요약과 해설이며 따옴표 인용을 쓰지 않는다(`tests/source-content.test.mts`가 확인).
- 요약에는 원문 내용만 담는다. Stack이 덧붙인 해석은 "내 고민과 연결해 보기"와 미니미션, 회고에 두고 화면에서 구분해 표시한다.
- 원문 보기는 원문 URL을 새 탭(`noopener noreferrer`)으로 연다. 가상 예시 자료에는 원문 보기가 없다.
- 데이터 위치: `src/config/source-contents.ts`(메타와 리더 데이터), 카탈로그 합치기 `src/config/catalog.ts`.

## 1. Why You Only Need to Test with 5 Users

| 항목 | 내용 |
|---|---|
| 자료 id | `nng-five-users-usability-testing` |
| 화면 제목 | 사용성 테스트, 몇 명에게 몇 번 해야 할까 |
| 원문 제목 | Why You Only Need to Test with 5 Users |
| 저자 | Jakob Nielsen |
| 발행 기관 | Nielsen Norman Group (NN/g) |
| 원문 URL | https://www.nngroup.com/articles/why-you-only-need-to-test-with-5-users/ |
| 발행일 | 2000-03-18 (페이지에 표기된 날짜. 다른 개정일은 페이지에서 확인되지 않음) |
| 원문 확인일 | 2026-10-17 (페이지를 직접 열어 두 번 확인) |
| 관련 학습 주제 | 사용성 테스트(`usability-test`) |
| 선정 이유 | 추천 공백 조사에서 자료가 0개이고 대표 조합에 가장 자주 걸린 주제(`docs/recommendation-gap-analysis.md`) |
| 자료 유형 | 개념 |
| 예상 시간 | Stack 요약을 읽는 시간 약 4분(요약 약 1,500자 기준), 미니미션 약 10분(선택) |

확인한 원문 내용(요약에 반영한 것만)
- 핵심 주장: 큰 연구 한 번보다 한 라운드 사용자 약 5명으로 작게 여러 번 반복하라. 목적은 결함 기록이 아니라 디자인 개선이다.
- 근거: 저자가 토머스 랜다우어와 만든 모델로 n명이 찾는 문제 수를 전체 문제 수 × (1 − (1 − L)의 n제곱)으로 어림한다. L의 평균은 약 31%. 5명이면 약 85%, 거의 전부를 찾으려면 약 15명.
- 5명씩 세 번이 한 번에 15명보다 낫다는 설명(1라운드 큰 문제, 2라운드 수정 확인과 더 깊은 문제, 3라운드 남은 문제).
- 1명이 부족한 이유(개인의 우연), 집단이 뚜렷이 다르면 집단별 인원(둘이면 3~4명, 셋 이상이면 최소 3명).
- 원문이 밝힌 전제: 이 식은 서로 비슷한 사용자에게만 성립하고 참가자는 대표 고객이어야 한다. 구체적인 서비스 사례는 없고 아이와 부모 같은 가정의 예만 나온다.

요약에서 **뺀 것**: 정량 연구 약 20명, 카드 소팅 약 15명은 본문이 아니라 후속 목록(사이드바)에만 있어 요약하지 않았다.

한계와 점검
- 원문은 2000년 글이다. 오래된 글이라는 점과 근거가 질적 테스트(문제 찾기)에 한정된다는 점은 화면의 "내 고민과 연결해 보기"에서 Stack의 해석으로 구분해 안내했다. 최신 후속 연구와의 비교는 하지 않았다.
- 원문 URL이 바뀌거나 사라질 수 있다. 링크 점검은 운영 단계(PRD F3-05 검수)에서 정해야 한다.
- 저작권과 인용 범위에 대한 운영자 검수는 하지 않았다(데모, 검수 전).

## 이번에 확인하지 못한 것과 점검 방법

- 요약에 쓴 내용은 페이지를 열어 확인한 범위이며, 페이지의 이미지에 담긴 내용은 확인하지 못했다.
- 세 원문 모두 링크 유효성은 확인일 기준이다. 운영 단계에서 주기적으로 점검해야 한다.
- 저작권과 인용 범위에 대한 운영자 검수는 하지 않았다(데모, 검수 전). 원문 전체나 긴 번역을 싣지 않았고 요약 문단은 400자 이하이며 따옴표 인용은 없다(`tests/source-content.test.mts`).
- 공식 문서와 원저자의 공개 글이라는 기준에서, HSE 가이드는 발행 기관이 분명한 공공 서비스 매뉴얼이지만 작성자와 날짜가 없어 가장 약한 출처다. 대체할 다른 공개 출처가 있으면 교체한다.
- 처음 조사한 Material Design 작성 가이드와 NN/g 마이크로카피 글은 본문을 열 수 없거나 주소가 없어 쓰지 않았다.
